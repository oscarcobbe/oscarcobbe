## How I work

I find the business problem, decide what to build, and test it against the real thing before it goes live: real bookings, real payments, real emails.

I build with AI coding tools (Claude Code). I set the requirements, review the work, and run the checks and the launch.

**Tools:** TypeScript, Next.js, Postgres (Supabase), Vercel, Stripe, Google Calendar API, Google Ads, GA4.
